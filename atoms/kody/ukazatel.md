# Коди («Указатель»)

## Обозначения

| Код | Значення |
|---|---|
| JB | челюстная кость |
| S | грудные контактные места |
| E | обработка уха |
| X | кровь |
| MB | парные точки |

У покажчику також трапляються: суфікси **M** / **B** у кодах (2M, 2B…), `левая` / `правая` — сторона тіла, `A+B` — точки, які натискають разом, `49(3и4)` — підточки 3 і 4 навколо пупка, `49,1/2` — точка 49½, «положительные / отрицательные ионы» — надруковано як є, без пояснення в книзі.

## Соматические контактные точки

Надруковано таблицею 4×4: `25 78 21 LT-X / 19 63 13B 5M / 10M 1B 2B 15M / 62 49 64 RT-X` (LT-X — ліва X, RT-X — права X).
